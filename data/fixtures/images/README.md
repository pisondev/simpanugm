# Synthetic image fixtures

This directory contains small, deterministic synthetic images with no people and no real
documents. They are generated by `data/scripts/create_fixture_images.py`:

| File | Purpose |
|---|---|
| `swatch-biru.png`, `swatch-merah.png` | solid colour extraction fixtures |
| `desk-gps.jpg` | media EXIF-removal fixture with synthetic GPS metadata |
| `mock-card.png` | OCR and masking fixture marked `CONTOH`, with fictional values |

Do not copy participant photographs or collected evaluation images here; those stay in the
private dataset workspace.

Recreate the assets after a deliberate fixture update with:

```text
python3 data/scripts/create_fixture_images.py
```

CI verifies that the committed bytes still match the generator:

```text
python3 data/scripts/create_fixture_images.py --check
```
