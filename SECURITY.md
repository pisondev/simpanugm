# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Use **Report a vulnerability** under the Security tab
of this repository, which opens a private advisory visible only to the maintainers.

Include what you found, how to reproduce it, and the impact you expect. We answer within
three days and keep you informed until it is fixed.

## Scope

The SimpanUGM application in this repository: `web`, `api`, `ml` and the deployment
configuration in `deploy`. Do not test against accounts or data that are not yours, and
do not attempt to access items, reports or claims of other people.

## Supported versions

Only the latest release on `main` receives security fixes.
