| 3 | Every service exposes liveness and readiness checks and shuts down gracefully | PASS | `api`: `/healthz` (liveness), `/readyz` (readiness verifying DB ping, goose migrations, and ML service reachability), graceful shutdown via `context.WithTimeout(..., 20*time.Second)` and HTTP server `Shutdown`. `web`: `/healthz` (liveness), `/readyz` (readiness verifying API reachability via `API_INTERNAL_URL`), Next.js runtime shutdown handler. `ml`: `/healthz` (liveness), `/readyz` (readiness checking model loading status in `app/routers/health.py`), graceful shutdown via lifespan task cancellation in `app/main.py`. |
