# Dashboard illustrations

These illustrations were supplied by the project owner in the local `transit-assets`
folder for use in the SimpanUGM interface and presentation. They are decorative
illustrations, not photographs of team members or an official university endorsement.

| Interface asset        | Supplied original                      |
| ---------------------- | -------------------------------------- |
| `owner-student.webp`   | `Cheerful Student with Smartphone.png` |
| `campus-entrance.webp` | `Serene UGM Campus Entrance.png`       |
| `finder-student.webp`  | `Cheerful Girl Tapping Smartphone.png` |

The officer illustration `officer-student.webp` is based on the supplied
`3D UGM Administrator with Clipboard.png`.

The administrator illustration `admin-student.webp` is based on the supplied
`Cheerful UGM Tech Learner.png`.

The WebP copies preserve the original proportions and character transparency, with
reduced resolution and file size for the dashboard. No third-party license is asserted
for the supplied originals. Demo item photographs retain their separate source and
license records in `data/demo/SOURCES.csv`.
