# web

The Next.js frontend for all four roles: members reporting and claiming, officers working
the queue and the desk, administrators managing and analysing. Mobile first, Indonesian
interface.

Owner: Pison Golda, with Axelle Chandra on the admin and analytics pages. Status:
specified, implementation starts in Sprint 1.
